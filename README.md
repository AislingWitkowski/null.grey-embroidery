# Embroidery
null.grey's 3D engine: real 3D in the browser, drawn in the station's crunchy style (low resolution, the station's
inks, 4×4 dither, film grain, thick fog, real lamps and shadows). First test: F03 Missing Mile's station.

Build: `npm install`, then `bash build.sh` → open `dist/missing-mile-station.html`.
Keys: w a s d · drag to look (double-click locks the mouse) · shift run · c crouch · space jump · 1 2 3 looks · 4 side by side · f frame rate.
Phone: hold to walk, hold low to step back, drag to look; jump and crouch buttons. Gamepad: sticks, A jump, B crouch, L3 run.
